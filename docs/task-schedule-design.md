# 任务日程视图（时间块）设计稿

> 2026-10-13。前置调研见 [task-schedule-research.md](./task-schedule-research.md)（结论：交互抄 Sunsama 两栏式，网格自研 `sag-time-grid`）。**本文已于同日实现落地**（迁移 0011、`sag-time-grid`、清单/日程双视图、AI 结构化排期），实现以代码为准。

## 一句话

任务页加一个「日程」视图：左边是没排期的任务清单，右边是周时间网格，**把任务拖上去变成时间块，拖下来变回任务**；「帮我排一排」升级成 AI 直接排出时间块、你过目后一键应用。

```

│                                                                    │
```

- **视图切换**：清单 / 日程 分段控件，位于原过滤 Tabs 一行；选「日程」时统计条、图表、过滤 Tabs 全部让位，两栏占满剩余高度（网格吃纵向空间）。
- **左栏（未排期）**：固定 300px。顶部一个快速添加输入（记下的事先进清单，再拖上格子）；下面是未排期且未完成的任务，按截止/优先级排序。
- **右栏（网格）**：弹性宽度，工具行（周切换 ‹ ›、今天、周/日切换）+ 网格本体。
- 头部按钮不动：新建任务仍是本页主按钮，「帮我排一排」仍为次按钮——两个视图共用。

## 时间网格（sag-time-grid）渲染规格

| 项       | 规格                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------ |
| 刻度     | 24 小时全高，每小时 56px（= 14px/15 分钟，块高度取整干净）；小时线 `border-border/60`，半小时线 `border-border/30` |
| 时间标签 | 左侧 44px gutter，`text-[10px] tabular-nums text-muted-foreground` 右对齐，只标整点                                |
| 周起始   | 周一；列头 = 周几 + 日期，`text-xs`                                                                                |
| 今日     | 列底色 `bg-primary/[0.03]` + 列头「今天」徽记（primary 前景/10 底）                                                |
| now 线   | 今日列 1.5px `primary` 实线 + 左端 6px 圆点，随分钟推进；组件内部 `isolation: isolate`，局部 z-index               |
| 初始滚动 | 07:30，让 8 点起的工作时段落在视口上部                                                                             |
| 窄窗口   | 列最小宽 80px，再窄横向滚动兜底（桌面场景可接受）；「日」视图随时可切                                              |

## 时间块视觉

一个信号一个通道：**状态决定块的色调，优先级只是块内一个小圆点，逾期只染左边条**。

| 状态       | 样式                                                              |
| ---------- | ----------------------------------------------------------------- |
| 待办       | `rounded-md border bg-card`，标题 `text-xs font-medium` 最多 2 行 |
| 进行中     | 边框 `border-primary/40` + 底 `bg-primary/[0.08]`                 |
| 已完成     | `bg-muted text-muted-foreground`，标题划线                        |
| 逾期未完成 | 左侧 2px `destructive` 边条                                       |

- 块内容：标题 + 时间区间（`text-[10px] tabular-nums text-muted-foreground`，如 `10:00–11:30`）+ 优先级小圆点（复用 `priorityDotClass`）。块高 ≤ 30 分钟时只显示标题单行。
- 重叠块：同日撞块按列均分宽度、2px 间距并排；允许重叠（不硬拦，Sunsama 同款自由度）。
- 高度 = 时长。24:00 封顶（单块不跨日）。

## 交互规格（按频次排序）

1. **拖入（清单 → 格子）**：行上 pointerdown 位移 >5px 进入拖拽；拖影是跟随光标的卡片（`shadow-lg`，只动 `transform`）。经过网格时落点显示半透明预览块（`primary/10`），高度 = 预估时长（无预估默认 30 分钟），15 分钟吸附；移出网格或按 Esc 取消。松手建块，块 150ms 淡入。
2. **框选新建**：空白处按下拖选一段（primary/10 蒙层），松手弹轻量 popover：标题 + 时间区间（可改）+ 优先级，回车即建。单击空白 = 默认 30 分钟，同 popover。
3. **移动 / 缩放**：块可整体拖动（跨日跨时，15 分钟吸附）；上下边缘 hover 出现 4px 拖拽热区可拉长短。拖动/缩放过程中显示当前 `start–end` 的小 tooltip。动效：跟手不动画，松手吸附 120ms `ease-out`。
4. **拖出（格子 → 左栏）**：块拖到左栏时左栏 `border-primary/40` 高亮，松手清空排期，任务回到清单（可再拖回，无需确认弹窗——操作本身可逆）。
5. **点击块**：打开现有编辑弹窗，新增「排期」区（日期 + 开始时间 + 时长）和「预估时长」字段，弹窗改时间与网格拖动是同一份数据。
6. **块上打勾**：块 hover 时左上角出现完成切换圈（与清单视图 Circle/CircleCheck 同语义同色）。
7. **键盘**：块可 Tab 聚焦（`focus-visible` ring），方向键 ±15 分钟移动，Shift+方向键缩放。时间计算是纯函数，好测。

## AI「帮我排一排」v2

- 点按钮 → 面板 loading（现有样式）→ 返回**结构化建议**而非一段文字：按天分组的块列表（`周一 10:00–11:30 · 写周报 · P1`）。
- 面板动作：**[应用到日程]**（批量写入，网格块按 30ms stagger 依次淡入）/ [重新排] / [收起]。
- AI 只建议、不落库——沿用现有「候选 → 过目 → 应用」模式（同 aiDraft）。
- 排期约束（v1 写进提示词，将来进了问题再来找设置页——管理进设置）：工作时段 9:00–18:00、避开午休 12:00–13:00、今日/逾期截止优先、尊重已有手动块。

## 视觉纪律（craft 对照）

- 无渐变、无 glow；阴影只给「浮着的东西」（拖影、popover），网格与块用 hairline 边框做结构（R1/R2/R10）。
- 间距全部 4px 基；块内 padding 6px（4 基 + 2 对齐半格）（R8）。
- 动效只动 `transform`/`opacity`，120–250ms，进 ease-out 退 ease-in，不循环不弹跳（R3/R12）。
- 网格是本视图唯一的大元素，左栏与工具行保持安静——层级一眼可辨（R4）。
- 所有交互态（hover/focus-visible/active/拖拽热区）显式设计，不留浏览器默认（R11）。

## 数据与后端

- **迁移 0010**：`tasks` 加 `start_at TEXT NOT NULL DEFAULT ''`、`end_at TEXT NOT NULL DEFAULT ''`、`estimate_minutes INTEGER NOT NULL DEFAULT 0`。
- 时间格式：本地无时区 ISO（`2026-10-14T14:00`），空串 = 未排期；与 `due_date` 同风格，前端/Rust 不做时区换算。
- Rust `Task` 模型加三字段，`upsert_task` 透传，无新表。
- AI 排期：改造 `suggest_task_plan` 返回严格 JSON，**Rust 侧解析校验**为 `Vec<PlanBlock>`（对齐 api_generate 的做法），坏 JSON 直接报错给 toast。
- 一个任务 v1 最多一个块：拖离 = 清空 start/end，任务保留。
